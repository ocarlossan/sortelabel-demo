# SorteLabel · demonstração

App do comprador, compilado, rodando com **dados de exemplo**. Serve para
mostrar o produto: não há API por trás, e nenhum valor, saldo ou sorteio
aqui é real.

Este repositório guarda apenas a saída do build. O código-fonte vive em
outro lugar, privado.

Para atualizar: refaça o build do app e substitua os arquivos.

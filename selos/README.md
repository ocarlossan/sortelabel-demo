# Selos e autorizações do rodapé

Coloque aqui as imagens dos selos (LOTEP, órgão estadual, etc.) e
registre cada uma em `utils/selos.ts`. Enquanto a lista estiver vazia, a faixa
inteira não renderiza.

Formato: PNG ou SVG com fundo transparente. A altura de exibição é 40px, então
mande pelo menos 80px de altura para telas 2x. Largura máxima 150px.
